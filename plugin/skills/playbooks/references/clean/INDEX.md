# Clean playbooks

Behavior-preserving refactors. Paths are relative to the playbooks skill.

- `references/clean/code-simplifier.md` — Simplifies and refines code for clarity, consistency, and maintainability while preserving behavior.
- `references/clean/repo-sweep.md` — Whole-repo cleanup (repo, docs, settings, UI, briefs, dead and replaced code): inventory every area, coverage as the done check.
- `references/clean/characterisation-tests.md` — Pin what untested code does today, before refactoring it.
- `references/clean/deprecation.md` — Retire a public surface: replacement first, shim, warn, announce, wait, remove.
- `references/clean/refactor-cleaner.md` — Dead code cleanup and consolidation, with analysis tools (knip, depcheck, ts-prune).

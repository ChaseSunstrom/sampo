# Review playbooks

Checklists, also read by sampo:fm-reviewer. Paths are relative to the playbooks skill.

- `references/review/code-reviewer.md` — Expert code review: quality, security, and maintainability.
- `references/review/cpp.md` — Expert C++ review: memory safety, modern C++ idioms, concurrency, performance.
- `references/review/python.md` — Expert Python review: PEP 8, Pythonic idioms, type hints, security.
- `references/review/rust.md` — Expert Rust review: ownership, lifetimes, error handling, unsafe usage.
- `references/review/security.md` — Vulnerability detection: secrets, SSRF, injection, unsafe deserialisation.
- `references/review/silent-failures.md` — Silent failures, swallowed errors, bad fallbacks, missing error propagation.
- `references/review/test-coverage.md` — Test coverage quality: behavioral coverage and its gaps.
- `references/review/type-design.md` — Type design: encapsulation, invariants, enforcement.
- `references/review/typescript.md` — Expert TypeScript and JavaScript review: type safety, async correctness, Node and web.
- `references/review/surface-parity.md` — A feature must reach every surface (CLI, plugin, app, pane): one source, a parity test from the code.

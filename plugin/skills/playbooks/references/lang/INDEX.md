# Language playbooks: beyond the per-language pairs

Paths are relative to the playbooks skill. The per-language patterns and testing playbooks are listed below.

- `references/lang/stdlib-python.md` — Before a Python dependency: job to stdlib module table, the version floor check, the safe forms, when a package wins.
- `references/lang/cpp-coding-standards.md` — C++ Core Guidelines, when writing or reviewing C++.
- `references/lang/cpp-testing.md` — GoogleTest and CTest, when fixing C++ tests.
- `references/lang/python-patterns.md` — Pythonic idioms, PEP 8, type hints, robust and efficient code.
- `references/lang/python-testing.md` — pytest, fixtures, mocking, parametrization.
- `references/lang/rust-patterns.md` — Idiomatic Rust: ownership, error handling, traits, concurrency.
- `references/lang/rust-testing.md` — Unit, integration, async and property-based tests in Rust.

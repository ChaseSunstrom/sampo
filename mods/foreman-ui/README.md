# foreman-ui

Sampo inside Claude Code: the docked pane, the band above the prompt, toasts and one-press actions. It installs as
`sampo-ui` (this folder keeps its old name):

    /plugin install sampo-ui --marketplace ChaseSunstrom/sampo

Tests: `claude plugin test mods/foreman-ui`.

- `tools/pane_replay.py render|twin FIXTURE` (T-1534): the pane drawn from a recorded `fm ui --json` view with no live
  session, through this mod's test kit; `twin` diffs two runs (`--matrix`: a third in another time zone and locale).
  Synthetic fixtures only in `tests/fixtures/`.
- Grants (T-1262): Ward asks for each `fm ask`; this mod answers that ask as its own (`tool.check`), so
  Claude Code puts it only to a person (the dialog, a host's callback or a PermissionRequest hook): auto mode's
  classifier, bypass mode or a saved rule for all of Bash can't approve it, and where nobody can be asked it is refused.
- `tools/shot.py` (T-0131): Claude Code with this mod in a tmux harness of its own, the screen as a PNG; `start DIR
  --view FIXTURE` (T-3701) has the mod draw a recorded view, so a screenshot shows the panels with no live state.
- The Board look (T-3701): `hooks/board-palette.ts` is generated by `tools/board_palette.py` from the live page's
  `plugin/web/live/board-tokens.json` (test_board fails when they drift); `look: forge` keeps the look before it (`palette` keeps fm code's words: default, cb, riso).
  The pane's instruments (lane clusters, merge flows, the CPU stack against its goal, gate cells, the history area) are
  pure cell functions in `hooks/kit.ts`, memoised per input, with text twins off the terminal; `tests/render-cost.test.tsx`
  prints what a draw costs on `tests/fixtures/board-busy.ts`.
- The board page (T-3701): the pane opens on the Board's top bar (SAMPO, the counts, the NOW strip, a callout with key
  caps when you're needed) over the live page Board's nine panels and SESSIONS (LANES, MERGE TRAIN, CPU, THE LOOP,
  LIBRARY, MODELS, SAMPO, STATE, SESSIONS, TESTS) in a grid of 3, 2 or 1 columns by width (`gridRows`: a short last
  row widens, so no slot is empty), drawn by
  `hooks/canvas.ts`: fills in half blocks (two pixels a cell), dots and hairlines in braille (2×4 a cell, a cell coloured
  by its brightest dot), words as cells; each panel's head carries the web's subtitle when it fits whole. The key caps
  are a visible plain Button beside a zero-width one holding the hotkey (the host prefixes a plain hotkey Button's
  label with `p:`); the host test API presses a Button by its element key only, so a live run proves the keys: in
  `tools/shot.py`'s harness, ctrl+x tab focuses the pane, then `p` turns the page and `a` approves. A short dock scrolls, the panels the state makes relevant first; only panels in
  the window draw. A picture's still layer is memoised per input and palette; only a moving one (a train's packets,
  models called in the last minute, a running test) draws a frame, at most ten a second (`FM-FRAME`, `FM-PIC` in
  `tests/pictures.test.tsx`; `FM-COST … tall=` in `tests/render-cost.test.tsx` draws all nine). `p` toggles the details
  page (the store keeps it). The view's `train`, lane `files`, `flows`, the task's `words` and `board` (cache/board.json,
  which a detached `fm ui --board-cache` refreshes at most every 30 s) feed them; none runs git or the network.
